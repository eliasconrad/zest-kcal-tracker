# Ideas for after the first release

Not built, on purpose: the first version is calorie tracking.

## Recipe books (Thermomix, Cookidoo)

A search on October 30, 2026 found no official public API for Cookidoo. What exists is unofficial and reverse-engineered, needs the person's Cookidoo password, and can break with any Cookidoo update, so Zest should not build on it. Better routes: import a recipe by its web link (most recipe sites publish structured recipe data), a photo of a cookbook page through the model, or asking Vorwerk about a partnership.

## Wearables

Start with Apple Health: it runs on the device with no backend, it covers Apple Watch, and many other trackers can write into it. It needs the HealthKit capability, so the Apple developer account has to be open again. Direct Garmin or Fitbit connections need partner access and a server, and are only worth it if Apple Health leaves a real gap. Android is a separate question; the app is iOS only today.
